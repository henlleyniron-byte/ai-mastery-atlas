Practice & Review release

Adds repeated workflow runs with fixed rubrics, explicit assistance/reviewer provenance, exact baseline links, a seven-complete-day delayed-retest protocol, a review queue, matched-condition comparison and exportable Markdown handoffs. These are user-recorded observations, not inspected artifacts or examination mastery.

The original working-note keys and all pre-existing evidence namespaces remain untouched. New run history uses a separate site-specific versioned key, validated JSON merge/restore, concurrent-write detection, exact raw exports and a previous-copy recovery slot. Private run storage is not read in studio share-safe mode. Home summaries also hide before reading private history in share-safe mode.

Handoff links carry only public workflow IDs and selected window/subject. Private artifact references remain in browser storage or user-created downloads.
