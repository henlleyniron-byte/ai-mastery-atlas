# AI Mastery Atlas V12 — Flagship Skill Workspace

The front workspace now includes the complete 180-task skill map. Learners can search objectives, filter by track and evidence stage, inspect prerequisite locks and open the exact existing task desk. Lists expand in groups of twelve. Private evidence stages are omitted when loading, recovering or using Share-safe; public task definitions remain available.

The session recommendation and evidence desk share one stage-specific brief: guided practice, independent demonstration, transfer, repair, delayed retention and maintenance each show the appropriate task and boundary. Session briefs can be inspected as complete text, downloaded as Markdown or copied with a manual-selection fallback. A brief is planning material and never advances evidence. The finder now expands beyond its former first-twelve limit, including all 159 source results.

No curriculum, rubric, evidence schema, prerequisites, retention intervals, namespace, hosting binding, dependency or access policy was changed. Product metadata and old version-title assertions now reflect V12.
