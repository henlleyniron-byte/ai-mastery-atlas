# Project history

AI Mastery Atlas was created and maintained in ChatGPT Sites before this public GitHub import. The retained commit history comes from that source repository; the public-import documentation commit adds this repository-facing README and preview.

The live deployment remains the primary user-facing release. GitHub is the public source and maintenance record from this import onward.

## 6 October 2026 — v5.2

Added a dated current-information guide, eight primary-source updates and six practical workflows. Integrated eight new official sources into existing ChatGPT lessons. Refreshed model guidance, including efficient-model routing and the current Gemini API catalog. Retained the 500-hour structure and browser-local learner-state schema. Current guidance is a manually verified snapshot; historical sources keep their own verification dates.

Follow-up correction: added the omitted Gemini 4 Argon announcement to the current guide, model register, Gemini pathway and lesson-linked source library. Availability is explicitly qualified.
