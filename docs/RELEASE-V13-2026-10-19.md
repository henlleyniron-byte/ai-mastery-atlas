# AI Mastery Atlas V13 — Focused Learning & Faster Labs

## What changed

Beginner Academy, Evaluation Workbench, Knowledge Systems Studio and Operator Core load their specialist code only when opened or addressed by a matching deep link. Opened workspaces remain mounted, so an ordinary parent update does not reset an in-progress draft. A visible loading shell, failure message, retry control and reload route replace silent loading gaps. Matching deep links retain their original section IDs, including the learning-science alias. Opening a lab directs focus to its heading when the visitor is not typing in another input.

The existing 180-task curriculum, rubrics, prerequisites, retention rules, evidence formats and source register remain intact. Session-brief export validation from the prior release is now covered by an exact-byte payload check and clipboard-denial/manual-selection test.

## Performance evidence

Same checkout, lockfile and production build environment:

| Main page JavaScript chunk | Prior V12 | V13 | Reduction |
| --- | ---: | ---: | ---: |
| Raw bytes | 798,429 | 604,071 | 24.34% |
| Locally gzip-compressed bytes | 241,759 | 187,369 | 22.50% |

These figures compare the main page chunk. They are not total application size, measured network transfer or a browser timing benchmark. The four specialist chunks remain available on demand. The existing warning for a chunk larger than 500 kB remains; it was not hidden.

## Validation

TypeScript, production build, whitespace checks and the full suite passed. With the DOM package supplied: 252 tests, 210 passed, zero failed, 42 unrelated optional private-fixture checks skipped.

New DOM interaction checks verify no specialist loader call before intent, one loader call on opening, draft preservation during parent rerender, matching and unrelated hash behaviour, fresh loader creation after a synthetic import failure, exact exported session text, clipboard denial and close behaviour. The harness uses linkedom and native-control shims. It does not establish real-browser layout or focus correctness.

The browser repeatedly failed to reconnect with an Emulation.setFocusEmulationEnabled timeout. Real-browser visual and interaction QA for this release is unavailable. All data used in testing was synthetic; no personal learner profile was changed.

## Reproduce DOM checks

Install linkedom 0.18.12 in a temporary test-only directory and set DOM_QA_PACKAGE to its absolute esm/index.js path:

    DOM_QA_PACKAGE=/absolute/test-only/node_modules/linkedom/esm/index.js node --test tests/*.test.mjs

No application dependency or lockfile was changed. The test package is not shipped to visitors.
