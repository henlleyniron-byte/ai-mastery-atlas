# Source-aware study prompt upgrade — 14 October 2026

The academic study lab now checks which materials are ready before preparing a diagnosis, repair or fresh-transfer prompt. These tasks require an unaided first attempt, marking, the exact question and a marking/resource excerpt. Source-audit and recall-card tasks require the source excerpt without inventing a completed exam attempt.

Task instructions are selected independently rather than presenting five unrelated jobs in every prompt. Transfer answers remain withheld until the learner attempts the exercise; source-audit prompts distinguish syllabus scope from question/answer authentication. Uncertain card facts are excluded. The default diagnostic intervals are +3/+10 days, with any valid increasing pair from 1–90 available. Changing any input clears a stale generated prompt.
