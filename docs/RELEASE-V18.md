# AI Mastery Atlas V18 — Retained Worksheet Recovery

Local candidate from published V17 `0eef6d5d19783c250eb04e782554f551f7e3d026`. Publication and root-owned full verification are separate gates.

The existing Paper Analysis Studio now exposes one selected retained copy as literal, labelled, keyboard-scrollable JSON and a direct private JSON download. Recovery does not depend on successful current-versus-retained comparison: an invalid current draft cannot strand an otherwise valid previous worksheet. A selected valid v1 export can be reviewed and imported directly. Invalid or future selected fields remain visible and exportable as explicitly unvalidated recovery JSON; strict v1 import and restoration continue to refuse them. JSON preserves recorded field values, not the original input file's formatting or raw bytes. Values that JSON would silently coerce or omit are refused rather than claimed lossless.

An explicit two-step restore validates only the selected v1 copy, then appends the entire preceding current draft—including empty, metadata-only or temporarily invalid working fields—to the retained archive. Every existing retained copy remains unchanged and returned model snapshots are detached from the originals. Restoration does not merge sources, alter review labels, resolve disagreements, generate answers or award academic evidence. At five previous sheets, replacement refuses without eviction. The selected JSON and complete recovery bundle can still be exported and checked before using a fresh private tab.

Current edits, copy changes, new imports and Share-safe transitions invalidate restore review. Live revision, selection, pending-import and privacy guards reject captured stale restore/export callbacks. In-flight imports have an explicit cancel control; their eventual results cannot reappear after cancellation/restoration. A captured older import-apply handler cannot apply a newer unreviewed file. Review and completion focus are labelled and keyboard reachable. The initial current/retained data remains in memory until deliberately replaced or the tab closes; exports request a download and do not prove backup success.

Recovery invalidation advances both an immediate guard and React revision state. A same-value retained-copy change event therefore refreshes the current controls even when the selected index and other fields do not change; older captured callbacks stay blocked. The mounted pre-fix regression reproduced otherwise visible recovery controls becoming inert after cancelling a late import. Its failing log and original component are preserved; the fix changes no worksheet values or retention limits.

The original strict `atlas-paper-audit-v1` format, 2 MB worksheet bound, 100-row bound and five-retained-copy preservation limit are unchanged. No new persistent store, academic namespace, schema migration, dependency, PHP, model call, account action, upload or cross-site transfer was added. Legacy V11 learner storage, protected specialist workflows, hosting identity and access policy remain outside this feature. The live Google foundation resource and its Gemini lesson placement remain intact.

Focused model and mounted DOM checks cover literal roundtrips, invalid/future recovery fields, selected-only validation, detached snapshots, capacity refusal, incomplete current preservation, stale edits/selections/privacy transitions, interrupted imports, explicit cancellation and focus. The initial local DOM run's textarea/defaultValue mismatch and earlier source are retained as diagnostic history; the final preview uses literal readonly text rather than a control-value shim. Root's full type/lint/build/regression and real-browser reports must identify their own completed, failed and skipped checks. This release note does not certify scientific classifications, keys, complete paper coverage, absolute security or unrun checks.
